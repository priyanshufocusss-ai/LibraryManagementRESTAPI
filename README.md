# Library Management REST API

## Project Description
A Library Management REST API developed using Spring Boot
to manage book records.

## Technologies Used
- Java
- Spring Boot
- Maven
- REST API
- Postman

## Book Fields
- id
- title
- author
- category
- availableCopies

## API Endpoints

| Method | Endpoint | Operation |
|---|---|---|
| POST | /books | Add Book |
| GET | /books | Get All Books |
| GET | /books/{id} | Get Book By ID |
| PUT | /books/{id} | Update Book |
| DELETE | /books/{id} | Delete Book |

## Testing
All API endpoints were tested using Postman.

## How to Run
Run EmployeeApplication.java from Eclipse.
